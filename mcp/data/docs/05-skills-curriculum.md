# Skills especializados (currícula)

Skills agregados/propuestos en `touchdesigner/skills/`:

- `td-fundamentals`: fundamentos y convenciones reproducibles.
- `td-project-architecture`: arquitectura de proyectos complejos y contratos.
- `td-performance`: presupuestos y profiling.
- `td-pops-advanced`: POPs avanzados + consulta técnica con `td_pops_query`.
- `td-integration`: integración POP↔SOP/TOP/CHOP/DAT y render/instancing.
- `td-robust-systems`: idempotencia, validación y reportes.

## Estructura recomendada por skill

- Objetivo
- Herramientas disponibles
- Reglas / checklist
- Plantilla de respuesta
- Validaciones y pruebas (smoke tests)

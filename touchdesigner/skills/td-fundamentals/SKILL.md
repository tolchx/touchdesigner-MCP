# td-fundamentals

## Objetivo

Traducir requerimientos a redes claras, idempotentes y verificables.

## Checklist mínimo

- Path de trabajo explícito (p.ej. `/project1`).
- Encapsulación en COMP cuando el sistema supera 10–15 operadores.
- Nombres consistentes y layout determinístico.
- Validación posterior con `td_operators` y/o `td_execute`.

# Color By Position
## Operators needed
- type: boxPOP → name: box1
- type: colorPOP → name: color1
## Connections
- box1 out → color1 in
## Parameters
- box1.num = 5000
- color1.method = position
- color1.scale = 1.0
## Description
Colors particles based on their world position. Creates rainbow gradients across particle clouds.

# GLSL Kaleidoscope
## Operators needed
- type: constantTOP → name: src1
- type: glslTOP → name: kaleido1
## Connections
- src1 out → kaleido1 in
## Parameters
- kaleido1.par.symmetry = 6
- kaleido1.par.angle = 0.0
## Description
Implements a kaleidoscope effect in GLSL for customizable symmetry patterns from any source image.

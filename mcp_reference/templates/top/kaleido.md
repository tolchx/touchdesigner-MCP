# Kaleidoscope
## Operators needed
- type: circleTOP → name: circle1
- type: kaleidoTOP → name: kaleido1
## Connections
- circle1 out → kaleido1 in
## Parameters
- circle1.radius = 0.5
- kaleido1.symmetry = 6
- kaleido1.angle = 0.0
## Description
Generates a kaleidoscope pattern from a circle source. Adjust symmetry for more/fewer mirrored sections.

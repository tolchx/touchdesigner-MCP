# Webcam → Displace
## Operators needed
- type: movieinTOP → name: webcam1
- type: displaceTOP → name: displace1
## Connections
- webcam1 out → displace1 in
## Parameters
- displace1.amp = 0.05
- displace1.phasex = 0.0
- displace1.phasey = 0.0
## Description
Feeds live webcam into a displace effect for organic distortion. Good for glitchy or warp effects on live video.

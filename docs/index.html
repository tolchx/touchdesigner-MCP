TouchDesigner MCP Server

Control TouchDesigner from any AI assistant via the Model Context Protocol — create operators, connect nodes, execute Python, and build complete visual networks.

60+ tools Online + Offline modes Multi-client compatible MIT License
📖 Docs interactivas GitHub npm

🚀 Características

  • 60+ tools — CRUD de operadores, parámetros, ejecución Python, networks
  • Modo online — Conexión directa a TouchDesigner vía HTTP API
  • Modo offline — Base de conocimiento local de TOPs, CHOPs, SOPs, POPs
  • Network Planner — Describe tu red en lenguaje natural y se construye sola
  • Batch execution — Ejecuta hasta 8 tools en una sola llamada
  • Watchdog — Monitoreo de rendimiento en tiempo real
  • Tutoriales — 5 tutoriales interactivos integrados
  • Workflows — 8 workflows reutilizables listos para usar

🔥 Instalación rápida

# Usando npm (global)
npm install -g touchdesigner-mcp

# O desde el repositorio
git clone https://github.com/tolchx/touchdesigner-MCP.git
cd touchdesigner/mcp
npm install
npx tsc

# Ejecutar
TDAPI_HOST=localhost TDAPI_PORT=44444 node dist/index.js

📋 Configuración MCP (Claude Desktop / Cursor / Windsurf)

{
  "mcpServers": {
    "touchdesigner": {
      "command": "node",
      "args": ["ruta/a/mcp/dist/index.js"],
      "env": {
        "TDAPI_HOST": "localhost",
        "TDAPI_PORT": "44444"
      }
    }
  }
}
